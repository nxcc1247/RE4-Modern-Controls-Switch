# 生化危机4 现代操作 MOD

Nintendo Switch 原版《生化危机4》现代操作 MOD，v1.0 首个公开正式版。

## 下载

在 [Releases](https://github.com/nxcc1247/RE4-Modern-Controls-Switch/releases) 下载 v1.0 安装包，解压后阅读 `安装教程.txt`。

## 功能

- 左摇杆按镜头方向全向移动。
- 右摇杆自由调整视角。
- 支持持枪移动、移动瞄准射击及不举枪时移动换弹。
- L3 冲刺、B 键换弹。
- 固定右肩视角，优化贴墙机位与动作衔接。

## 适用环境

Nintendo Switch 原版《生化危机4》1.0.2，Title ID `010099A00BC1E000`，使用 Atmosphère 加载。使用摇杆瞄准。主要针对 Leon，其他角色、部分武器和完整流程尚未全面验证。

## 安装

完全退出游戏，将安装包中的 `atmosphere` 合并到 SD 卡根目录。安装前请备份已有的同游戏操作或镜头补丁及 `subsdk1`，并将冲突补丁移出加载目录。完整步骤和卸载方法见包内教程。
